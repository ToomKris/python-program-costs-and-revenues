# 💰 Budget Management App

A simple budget management app built with **HTML, CSS, and JavaScript**.

## Features

* ➕ Add money
* ➖ Spend money
* 📊 Check balances
* 🍔 Food
* 🚗 Transport
* 🏠 Household
* 🎮 Entertainment

## Technologies

* HTML
* CSS
* JavaScript

## How to Use

Open `index.html` in a web browser, or visit the **GitHub Pages** website.

## Project Structure

```text
├── index.html
├── style.css
└── script.js
```

Originally created as a Python + EasyGUI project and later converted into a web application.
